elo101

Privacy

Last updated November 19, 2026.

elo101 is a free chess game review. Stockfish and the review models run in your browser. There is no account, we don't show ads, and we don't sell your data.

The Chrome extension

On Chess.com and Lichess the extension shows a small Elo101 button. It reads the current page's address to recognise a supported game. On Chess.com, clicking the button or opening the popup may also read a player name from links on the game page, so elo101 can find that game in Chess.com's public archives. When you choose to review a game, it opens elo101 with the game link and, if found, that player name in the address.

After one of your own games ends, the extension can show a short bubble offering a review. To know a game has ended it checks only whether the clocks are running, your own resign or abort buttons, and the result text. It never reads the board or the moves, and shows nothing while your game is in progress. You can turn the bubbles off in the extension popup.

The extension stores, on your device only: whether bubbles are on, the results (win, loss or draw) of your last few games for the losing-streak message, and which message it showed last. It does not send data to us or anyone else, does not include analytics, and does not run on other sites.

The website

To import a game, your browser requests public game data directly from Chess.com or Lichess. Analysis, move labels and ratings are calculated in your browser. The site keeps up to five recently reviewed games (including their PGN), remembered usernames and your settings in your browser's local storage. You can remove them by clearing site data for elo101.vercel.app in your browser settings.

The site is hosted on Vercel, so opening it sends normal request data such as your IP address to Vercel. Fonts load from Google Fonts. When elo101 opens from the extension, the game link and player name are read from the address and then removed from it.

Analytics

We use two analytics tools to understand how the site is used and to fix problems:

  • Vercel Web Analytics counts visits and page views using aggregated data and no cookies.
  • PostHog records page views, clicks, errors and a few product events (for example that an analysis started or finished, how long it took, how many moves the game had, or that a review or Retry was opened). It may also record anonymous session replays of how the page is used; text you type into fields is masked and not recorded. PostHog keeps an anonymous ID in your browser's local storage, not in a cookie. We remove the query part of every page address before it is sent, so game links and player names from the extension are not included.

We don't send your PGN or the engine's analysis as analytics data, and we don't use analytics for advertising or to identify you.

Limited use

Information accessed through Chrome extension permissions is used only to open your game in elo101 and to show the post-game bubble. We do not use or transfer it for advertising, profiling or unrelated purposes. Our use of information received from Chrome APIs follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

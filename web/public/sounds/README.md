# Sounds

Lichess "standard" sound set, from
[lichess-org/lila](https://github.com/lichess-org/lila/tree/master/public/sound/standard).
Lichess lists these files as non-free (see its COPYING.md); they are not covered by this repo's MIT license. Renamed:

| File | Lichess standard file |
| --- | --- |
| move-self.mp3, move-opponent.mp3, castle.mp3, promote.mp3, move-check.mp3 | Move.mp3 (Lichess's standard Check.mp3 is silence) |
| capture.mp3 | Capture.mp3 |
| game-start.mp3, game-end.mp3, notify.mp3 | GenericNotify.mp3 |
| illegal.mp3 | Error.mp3 |

Review a game

Open a completed Chess.com or Lichess game and select the Elo101 button on the page, or click the extension icon and choose Review game. Elo101 opens in a new tab and starts the review.

If a game cannot be found

Chess.com public game archives can take time to update after a game ends. Try again later, enter either player’s username in Elo101, or paste the game PGN. Daily game links are not supported yet.
